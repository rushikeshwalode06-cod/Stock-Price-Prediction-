# 📈 Stock-Price-Prediction
Stock Price Prediction is a machine learning project that forecasts future stock prices using historical data. It applies algorithms like Linear Regression and time-series models to identify trends and patterns, helping investors make informed decisions by predicting market movements with improved accuracy.

# 📈 Stock Price Prediction using Machine Learning

## 📌 Overview

Stock Price Prediction is a machine learning project that analyzes historical stock data such as open, high, low, close prices, volume, and trends to forecast future prices. The project helps in understanding market patterns and supports better investment decisions.

![ml](https://github.com/rushikeshwalode06-cod/Stock-Price-Prediction-/blob/main/Stock%20price%20prediction.png?raw=true)

## 🚀 Features
🧹 Data Preprocessing and Cleaning
📈 Model Training using Linear Regression / Time-Series
🔮 Prediction of Future Stock Prices
📊 Performance Evaluation using Metrics

## 🛠️ Technologies Used
* 🐍 Python
* 🔢 NumPy
* 🐼 Pandas
* 📊 Matplotlib / Seaborn
* 🤖 Scikit-learn

## 📊 Dataset
Historical stock price dataset 
Contains features like:
1. Open price
2. High price
3. Low price
4. Volume
5. Close price (Target Variable )

## ⚙️ How It Works
📂 Load the Dataset
🧹 Clean and Preprocess the Data
✂️ Split Data into Training and Testing Sets
🤖 Train the Model (Linear Regression / Time-Series)
🔮 Predict Future Stock Prices
📊 Evaluate Model Performance

## 📈 Model Used
**Linear Regression** 

![ml](https://github.com/rushikeshwalode06-cod/Stock-Price-Prediction-/blob/main/Stock%20Price%20Graph%20.jpeg?raw=true)

## 📉 Evaluation Metrics
* R² Score

## 🎯 Conclusion
This project demonstrates how machine learning can be used to predict stock prices by analyzing historical trends. While predictions may not be 100% accurate, the model provides valuable insights for understanding market behavior.This Stock Price Prediction project successfully uses Linear Regression to predict stock closing prices based on market features such as Open, High, Low, and Volume. The data is cleaned, split into training and testing sets, and the model is evaluated using the R² Score.
